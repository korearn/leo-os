# Atabook: cómo dejarlo con la estética de LeOS

Se edita en el panel de Atabook → Guestbook layout. Gratis: colores, fuentes, fondo y la imagen del encabezado.
El CSS propio solo viene con el plan Supporter (de pago).

## Encabezado
Sube `header.png` (600×120) como logo/imagen del encabezado.

## Colores (los mismos tokens de style.css)
| Parte | Color |
|---|---|
| Fondo de la página | `#120f2e` (o la imagen `https://leo-os.neocities.org/img/bg/estrellas.gif`, en mosaico) |
| Fondo del libro / del formulario | `#2a2463` |
| Fondo de cada mensaje | `#1b1650` |
| Bordes | `#7b5cff` |
| Texto | `#e8f4ff` |
| Fechas y texto secundario | `#9aa6d6` |
| Enlaces | `#5fe0ff` (al pasar el mouse: `#ffc20e`) |
| Campos (nombre, mensaje) | fondo `#0b0920`, texto `#e8f4ff`, borde `#7b5cff` |
| Botón Enviar | fondo `#ffc20e`, texto `#120f2e` |
| Respuestas del dueño | fondo `#0a3a9e` (el azul de selección) |

## Fuente
Verdana o Tahoma, 13px (la misma familia que el texto del sitio). Pixelify no viene en Atabook.
